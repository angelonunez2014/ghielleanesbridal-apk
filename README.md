# Ghielleane's Bridal — Android App

Android app for **Ghielleane's Bridal & Fashion Collection** order tracking.
It opens the web app at https://ghielleanesbridal.web.app inside a native shell.

## Download

**[Download the latest APK](https://github.com/angelonunez2014/ghielleanesbridal-apk/releases/latest/download/ghielleanesbridal.apk)**

All versions: [Releases](https://github.com/angelonunez2014/ghielleanesbridal-apk/releases)

## Install

1. Open the download link above on your Android phone.
2. Open the downloaded `ghielleanesbridal.apk`.
3. If asked, allow your browser or Files app to **install unknown apps**.
4. Tap **Install**. A newer version installs over the old one; you don't need to uninstall first.

Requires Android 7.0 or newer. Sign in with your shop account after opening the app.
